# Project: Company Profile ARTIC (Transwater Robery Indonesia)

Tujuan: Membuat website company profile statis yang modern dan profesional.

## Struktur Halaman:
1. Home: Hero section dengan visual air segar, ringkasan perusahaan.
2. About Us: Visi misi dan kualitas air ARTIC.
3. Products: Galeri produk (330ml, 600ml, Galon).
4. Contact: Lokasi dan formulir kontak.

## Teknis:
- Gunakan HTML5 dan Tailwind CSS (via CDN agar mudah).
- Gunakan JavaScript untuk navigasi simpel/interaksi.
- Tampilan harus responsif (Mobile Friendly).
- Nuansa warna: Biru cerah (seperti air) dan putih bersih.

Tolong buatkan struktur file dasar untuk proyek ini dan berikan kode untuk halaman utama (index.html).
